# 飞升：从对话到音乐影像

## 先确定选择，再安排奇观

初稿以红绸和超现实建筑为主。画面成立，但用户认为故事性、主角和刺激点不足。后来加入红衣信使，把“城市静止—夺取光种—追逐—主动跃下—逆转重力—归返”连成英雄之旅。主角最后的飞升来自她的决定，而不只是特效。

角色参考锁定成年东亚女性、短黑发、酒红外套、黑色内搭、金色腕线与光种。每个镜头先写清楚她知道什么、想做什么、为什么会进入下一个镜头。

## 用可视化讨论收敛审美

历史页面保留了从 v3 到 v6 的设计变化。用户指出过画面油亮、塑料感强的问题，并选择更柔和的暖灰方向。随后以独立分镜强化人物和动作，而不只做一整张拼图。

v11 再把纸感、地貌纹理、陶土电影色和蓝晒做成风格实验。首帧本身经过 AI 图像服务重绘，LoRA 参与后续本地视频生成，因此不能把所有风格变化都归因于 LoRA。16-C 与 19-D 保留了同首帧、同提示词、同种子和步数的关闭 LoRA 对照。

## 把图片变成有方向的动作

提示词由固定身份、一个主动作、景别、机位、镜头运动和结束状态组成。复杂动作拆成多个镜头，避免同一段同时承担奔跑、转身、跳跃、变形和场景切换。参考图用于约束外观，尾帧和引导帧用于约束落点；参考视频用于运动或角色条件的试验。

本地生成采用单任务队列。完成后抽帧检查身份、道具、肢体、视线、运动方向和背景跳变，决定保留、裁切、改变入点或重做。失败记录也是工程的一部分。

## 剪辑让镜头彼此需要

先分析音乐瞬态和强弱变化，再结合实际动作决定切点。切在节拍上并不足够，还要看前镜的动作趋势是否能接入后镜。历史精修记录调整过 32 处旧切点，并检查了奔跑、下降、上升与天幕段的源入点。

剪映 MCP 用于创建草稿和安排时间线；实际界面用于验证工程显示及导出。曾遇到源草稿加密无法解析、内置滤镜触发会员导出限制等问题。最终通过已留存素材重建普通草稿，并使用本地生成的调色与光影素材解决，而非把未成功的步骤写成成功。

## 验证与版本

历史精修母版保留了 41 段画面、40 个切点检查、音频同步与素材校验记录。网站播放作者最后指定的普通导出版本，两者时长不同，分别标记。公开副本移除本机路径与媒体元数据，使用新的下载校验清单。

人的工作是表达方向、选择版本、提出修改。AI 的工作包括理解这些指令、编排工具、生成和验证。整个系统是多种工具协作，不依赖一种神奇提示词。
