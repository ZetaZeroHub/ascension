# 剪辑工程与迁移

素材包中的 `site/editing/` 保存普通导出版本的 MCP 编辑清单、时间线、片段、光影层、音乐及历史草稿备份。公开版绝对路径已去除，不能直接当作原电脑上的工程目录。

1. 下载并解压全部媒体包，保留目录结构。
2. 执行 `python scripts/relocate_edit.py --output local-edit.json`。它在 `site/editing/` 中解析素材，写出适合本机的绝对路径清单；缺少或重名冲突的素材会报错。
3. 安装 [jianying-ai-mcp](https://github.com/Xanthus-Sanslab/jianying-ai-mcp)，按其工具 schema 把新清单交给 `build_draft`，先进行 `dry_run`，使用新工程名。
4. 在自己的剪映版本中打开新工程，检查人物、切点、音画同步和特效，再导出。不要覆盖正在编辑的草稿。

留存时剪映为 11.5.0.14471，MCP 验证基线为 10.0.5.13816。工具返回成功不能替代画面验证。历史原生草稿作为参考保存，新机器优先通过重定位后的 MCP 清单重建。

网站成片：约 93.762 秒。历史验证母版：约 95.083 秒，24fps，2282 帧。历史校验文件中的路径和哈希用于理解当时记录；下载包完整性使用 Release 的新 SHA256。
