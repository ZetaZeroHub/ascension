# 剪辑时间线与素材替换

公开版保存 MCP 编辑清单、时间线、切点调整与静态抽帧对照。按作者要求，原始/衍生视频片段、光影视频层和独立音乐文件只保存在作者本机，不上传网站或 GitHub。网站只提供最后指定的完整 MV。因此这里是可学习、可替换素材的制作记录，不是下载后即可原样恢复的完整剪辑包。

1. 阅读 `site/editing/` 中的时间线和 MCP 清单，参考静态切点对照。
2. 使用公开 ComfyUI 工作流自行生成镜头，或换成自己的素材和音乐，按清单校对时长与入出点。
3. 在本地补齐所需素材后，运行 `python scripts/relocate_edit.py --output local-edit.json`。缺少素材时脚本会报错，属于预期行为；它不会伪造素材或覆盖工程。
4. 安装 [jianying-ai-mcp](https://github.com/Xanthus-Sanslab/jianying-ai-mcp)，按工具 schema 使用新清单构建草稿，先 `dry_run`，再以新工程名保存。
5. 在剪映中检查人物、切点、音画同步和特效，再导出。

历史环境：剪映 11.5.0.14471，MCP 验证基线 10.0.5.13816。原生加密草稿未公开。网站指定导出约 93.762 秒；历史验证母版约 95.083 秒。历史哈希与画面验证对应各自原始版本，不能当作压缩预览图的新哈希。
