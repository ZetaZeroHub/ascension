# 《飞升》后续镜头：5 分钟快速档

用于**新增约 5.17 秒的视频镜头**。现有 `高清素材-v10` 批次继续交付原生 720p、25 步版本；新增镜头默认从本机已验证的快速配置开始，关键镜头再选高清配置。

| 项目 | 快速档设置 |
| --- | --- |
| 模型 | `minimax_h3_fl2va_pruned_int8_convrot.safetensors` |
| 加速 | `minimax_h3_fl2v_turbo_8step_v1.0_comfyui_bf16.safetensors`，强度 1.0 |
| 文本编码器 / VAE | `qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors` / `minimax_h3_video_vae_int8_convrot.safetensors` |
| 采样 | `res_multistep`，`simple`，8 步，denoise 1.0 |
| 模型原生尺寸 | 640×384，124 帧，24fps |
| 剪辑输出 | 居中裁切至 640×360，再以 Lanczos 缩放到 1280×720，24fps |
| 声音 | 独立镜头静音，剪辑时使用原曲 |

本机已完成的 10 个同规格镜头，ComfyUI 单段执行耗时 **174.3–209.1 秒**，中位数 **183.8 秒**。这是模型执行时间，不含首帧制作、排队、人工验收与最终打包；未验证所有后期环节都能在 5 分钟内结束。已验证工作流可从 [`补充与舞蹈-v9/workflows/20-API.json`](补充与舞蹈-v9/workflows/20-API.json) 复制。新镜头需替换 `LoadImage` 的首帧、提示词、随机种子及 `SaveVideo` 前缀；保留 LoRA 连接和 8 步设置。

已准备可直接导入 ComfyUI API 的 [`22-example-API.json`](快速档-5分钟/22-example-API.json)，它对应第 22 镜头的原首帧，仅作为已验证参数示例，**未额外提交生成任务**。为新的首帧生成独立工作流，可运行 `work/feisheng/quick5/create_workflow.py --image <首帧图片> --slug <英文镜头名> --seed <整数> --prompt-file <UTF-8提示词文本>`；脚本会把首帧复制到 ComfyUI input 并保存完整 API JSON，不会占用正在运行的生成队列。

快速档的 720p 是文件尺寸，不是原生细节。近景脸部、手部以及快速旋转的精细纹理会比 `高清素材-v10` 的原生 720p、25 步版本软；适合先出动作与构图草稿、过门和中远景，不把它标作高清母版。用户若说的是**静态分镜图**，这份 H3 视频预设不适用；静态首帧由内置生图工具制作，没有此工作流的采样步数设置。
