# 《飞升》高清 10 镜头逐镜验收基准

这批交付是 13–22 号镜头的重新生成：原生 1280×736、25 步、无 Turbo LoRA，中心裁为 1280×720、24fps、124 帧（5.1667 秒），另提供运动补偿插帧的 48fps、248 帧版本。48fps 不代表模型原生生成帧；两版时长必须相同。

| 镜头 | 画面动作验收重点 | 特别留意 |
|---|---|---|
| 13 握紧种子 | 同一只手握住单颗裂纹金种子，亮度随动作变化 | 手指数目、种子轮廓、手环连续性 |
| 14 断桥脚步 | 靴子在桥缘小幅前进，石屑坠落 | 靴子不穿过地面，桥缘和碎石轨迹连续 |
| 15 核心涟漪 | 单颗种子静止，主光环由内向外扩散 | 种子不复制、环纹不倒退或突跳 |
| 16 归来回望 | 主角回头、停顿、浅笑 | 五官、短发、酒红外套和背景透视连续 |
| 17 正面群舞 | 主角与两位伴舞分层，侧步后张开手臂 | 人物不粘连，手臂数目正确，白雕塑不移动 |
| 18 低机位独舞 | 下蹲、起身、右臂斜向伸展 | 双脚着地，膝盖与手臂不扭曲，石翼静止 |
| 19 侧面行进 | 侧面右移，躯干与双臂流动 | 侧脸一致，伴舞保持独立，横移无空间跳变 |
| 20 俯拍旋转 | 主角半圈转身，衣摆自然展开收拢 | 人物不复制，四肢和伴舞旋转轨迹合理 |
| 21 近景律动 | 胸部律动、视线转向镜头、前臂掠过 | 近景脸部与手部连续，插帧不扭曲眼鼻嘴 |
| 22 后方收束 | 主角从后方前行、转向镜头，伴舞抬臂 | 人物队形、白雕塑与景观位置稳定 |

每段需核对 ComfyUI 成功历史、工作流参数、完整解码与无黑帧、尺寸/帧率/时长、SHA256、24fps 与 48fps 抽帧、新旧同时间画面对照，以及强运动位置的原生帧／插帧／下一原生帧三联。16、21 额外检查放大的人像时间线。视觉验收结果记入 `视觉验收.json`；技术通过不能替代画面验收。
