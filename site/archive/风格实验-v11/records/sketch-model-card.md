## Usage instructions

Lora Strength between 0.75 and 1.25 for most applications, if using with a turbo LORA you might want to increase strength further.

Use the following prompt but you can remove anime to get a more western style sketch: " A hand-drawn 2D anime art style characterized by rough, textured outlines, coloring technique is minimalist, utilizing flat colors and white outline"
